# Org Chart by TCViz

A free org chart for Power BI — every feature, no licence, no limit on people, no watermark.

- **Two fields draw it.** Employee ID and Manager ID, any depth. Add name, job title, department, photo and a measure.
- **Large organisations stay readable.** Opens as many levels as fit, compact layout, search, zoom, minimap, and *Show only this team* with breadcrumb navigation.
- **Real data.** Reporting loops, repeated IDs and missing managers are handled and reported. Vacancies and dotted-line managers.
- **Power BI.** Select a person or a whole team, highlighting, bookmarks, report page tooltips, fx on card colour, format on the canvas, keyboard navigation, high contrast, Format pane in 12 languages.
- **Private.** No network access: nothing leaves your report.
