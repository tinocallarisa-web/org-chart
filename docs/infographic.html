Free org chart from two columns: employee and manager. Photos, search and a breadcrumb.

Who reports to whom, and how big is each team?  ·  Sample data: Begudes Nord, a fictitious drinks company — drawn by the visual, Report theme

Fields

Employee IDOne row per person.
Manager IDThe employee ID of each person's manager; empty for the top of the tree.
Name, Job title, DepartmentText shown on each card; department also colours and groups the cards.
PhotoImage already embedded in the model as Base64; links to web images are not loaded.
Dotted-line manager IDA second manager for matrix teams, drawn as a dashed link.
Value, Color value, TooltipsA figure per card and per team, a measure for colour, and extra tooltip figures.

Get started

  1. Install Org Chart by TCViz from Microsoft AppSource
  2. Drag the employee ID into Employee ID and the manager ID into Manager ID
  3. Add Name, Job title, Department, Photo and a measure in Value
  4. Pick a style, set each department's colour, and click a card to filter the report
