1. Overview

Org Chart by TCViz is a Power BI custom visual developed by TCViz (Tino Callarisa). An org chart usually shows personal data — names, job titles, photos — so this page says exactly what happens to it.

2. Data collection

The visual does not collect, transmit or store any data outside your report. Building the hierarchy, counting teams, searching and drawing all happen inside Power BI, on the data of your report.

3. No network access

The visual declares no network privileges ("privileges": []), so Power BI does not let it make any web request. That is why photos must be stored in your model as Base64: a link to a photo on a web server is not loaded.

The Open the guide button on the start page asks Power BI to open this documentation in your browser; Power BI shows you the address and asks before opening it. The visual sends nothing.

4. What the visual saves in your report

To keep your view when filters change or the data refreshes, the visual saves in the report which branches you opened or closed and which team you focused on — as a list of Employee IDs, in the report file itself, like any formatting setting. No names, photos or values are saved.

5. Cookies and storage

No cookies, no browser storage, no licence check.

6. Third parties

No analytics, tracking or advertising.
